# WhatsApp Business Cloud API

This bundle provides connection-backed WhatsApp Business Cloud API actions and webhook events.

Send Text, Send Template, and Reply to Message support Tool Mode. Agents supply recipients and message text or template names, languages, and positional body parameters. Reply to Message uses its configured inbound event and lets the agent supply only the reply text. Connections and the server's app, WABA, and phone settings stay configured. Existing template validation and provider checks still apply. The webhook trigger starts flows and does not expose an agent tool.

See the [WhatsApp Business Cloud API setup guide](https://docs.langflow.org/next/bundles-whatsapp) for installation, permissions, supported environments, receiver setup, and recovery. The guide's source is [bundles-whatsapp.mdx](../../../docs/docs/Components/bundles-whatsapp.mdx).
