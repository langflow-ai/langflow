# Confluence Cloud integrations

This preview bundle provides four page actions and two polling triggers for an approved Confluence Cloud site. The Confluence Integrations category is separate from legacy Confluence components, whose saved-flow identities are unchanged.

Follow the [Confluence Cloud setup guide](https://docs.langflow.org/next/bundles-confluence) for Atlassian application registration, deployment configuration, connections, background runs, event identity, limits, and recovery. The maintained [guide source](../../../docs/docs/Components/bundles-confluence.mdx) ships with the next-version documentation.

The [provider contract](../../../design/provider-integrations/contracts/confluence.v1.json) records capabilities and acceptance evidence. Live tenant authorization and production delivery acceptance remain unverified.
