# ServiceNow integration

This bundle provides approved-table actions and observed ticket changes through the ServiceNow Table API.

Read the [ServiceNow setup and recovery guide](https://docs.langflow.org/next/bundles-servicenow) for app registration, supported environments, permissions, polling limits, and recovery. Its source is [bundles-servicenow.mdx](../../../docs/docs/Components/bundles-servicenow.mdx).
