# GitLab integrations

This preview bundle provides nine actions and two signed project webhook triggers. Actions run as the verified personal access token owner.

Follow the [GitLab setup guide](https://docs.langflow.org/next/bundles-gitlab) for personal access token setup, deployment configuration, connections, background runs, event identity, limits, and recovery. The maintained [guide source](../../../docs/docs/Components/bundles-gitlab.mdx) ships with the next-version documentation.

The [provider contract](../../../design/provider-integrations/contracts/gitlab.v1.json) records capabilities and acceptance evidence. Live tenant authorization and production delivery acceptance remain unverified.
