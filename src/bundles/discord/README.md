# Discord integration

This bundle provides bot message actions and declarations for supervised Gateway message and mention triggers. Install it with Langflow to run triggers. Actions use the shared lfx connection resolver and also work without the server package.

See [Discord setup and recovery](../../../design/provider-integrations/discord.md) for permissions, supported contexts, receiver ownership, and delivery limits. Slash commands and interaction responses are unsupported. Live Discord tenant validation and owner acceptance remain pending.
