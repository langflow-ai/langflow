This guide explains how to deploy Langflow on [Easypanel](https://easypanel.io), a self-hosted Docker deployment platform.

1. Install [Easypanel](https://easypanel.io/docs/installation) on your own server, if you haven't already.

2. Follow this link to deploy the Langflow template on Easypanel:

   [![Deploy on Easypanel](https://easypanel.io/img/deploy-on-easypanel-40.svg)](https://easypanel.io/templates/langflow)

3. Click **Deploy**.

   The template automatically provisions a PostgreSQL database and configures Langflow to use it.

4. Wait for the deployment to complete.

5. Navigate to your Langflow instance at the domain Easypanel assigns to the service.
