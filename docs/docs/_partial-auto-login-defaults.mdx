:::note
Official release packages, tagged source archives, and Docker images disable automatic login by default.

For a new installation, set `LANGFLOW_SUPERUSER_PASSWORD` before starting Langflow, then sign in with the username `langflow` (or your configured `LANGFLOW_SUPERUSER`).

For an existing auto-login installation, setting `LANGFLOW_SUPERUSER_PASSWORD` does not replace that account's non-legacy password. [Prepare the existing account for password sign-in](/api-keys-and-authentication#upgrade-from-auto-login) before you switch to password sign-in.

Development branches retain automatic login by default.
For trusted local development, set `LANGFLOW_AUTO_LOGIN=true`.
For more information, see [`LANGFLOW_AUTO_LOGIN`](/api-keys-and-authentication#langflow-auto-login).
:::
