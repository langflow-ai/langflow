[Opik](https://www.comet.com/site/products/opik/) is an open-source platform for evaluating, testing, and monitoring LLM applications. You can configure Langflow to collect tracing data about flow executions and send it to Opik automatically.

For end-to-end integration details, see the official [Opik + Langflow guide](https://www.comet.com/docs/opik/integrations/langflow).

## Prerequisites

- An [Open-Source Opik server or an Opik Cloud account](https://www.comet.com/docs/opik/faq#what-is-the-difference-between-opik-cloud-and-the-open-source-opik-platform-)
- A [running Langflow server](/get-started-installation) with a [flow](/concepts-flows) that you want to trace

:::tip
If you need a flow to test the Opik integration, see the [Langflow quickstart](/get-started-quickstart).
:::

## Configure Opik for Langflow

Set the Opik environment variables in the process that runs Langflow. Langflow checks for an API key or a server URL before it initializes the Opik SDK, including when you have already run `opik configure`.

### Opik Cloud

Get an [Opik API key](https://www.comet.com/docs/opik/faq#where-can-i-find-my-opik-api-key-) and replace the placeholders with your key and workspace name.

<Tabs>
<TabItem value="linux-macos" label="Linux or macOS" default>

```bash
export OPIK_API_KEY=YOUR_API_KEY
export OPIK_WORKSPACE=YOUR_WORKSPACE
```

</TabItem>
<TabItem value="windows" label="Windows (Command Prompt)">

```batch
set "OPIK_API_KEY=YOUR_API_KEY"
set "OPIK_WORKSPACE=YOUR_WORKSPACE"
```

</TabItem>
</Tabs>

### Self-hosted Opik

Set `OPIK_URL_OVERRIDE` to the API endpoint of your Opik instance. Replace the example URL with the address that Langflow can reach.

<Tabs>
<TabItem value="linux-macos" label="Linux or macOS" default>

```bash
export OPIK_URL_OVERRIDE=https://opik.example.com/api
```

</TabItem>
<TabItem value="windows" label="Windows (Command Prompt)">

```batch
set "OPIK_URL_OVERRIDE=https://opik.example.com/api"
```

</TabItem>
</Tabs>

### Verify tracing

Start or restart Langflow in the environment you configured. Run a flow, then open your Opik dashboard and look for its trace.

```bash title="Start Langflow"
uv run langflow run
```

## Run Langflow with Docker Compose

For Opik Cloud, pass your API key and workspace name to the Langflow container.

```yaml title="docker-compose.yml"
services:
  langflow:
    image: langflowai/langflow:latest
    environment:
      - OPIK_API_KEY=${OPIK_API_KEY}
      - OPIK_WORKSPACE=${OPIK_WORKSPACE}
```

For self-hosted Opik, pass `OPIK_URL_OVERRIDE` with an API URL reachable from inside the container. Recreate the Langflow container after changing its environment.

## Disable Opik tracing

Remove `OPIK_API_KEY` and `OPIK_URL_OVERRIDE` from the Langflow process environment, then restart Langflow. Other applications can keep their Opik SDK configuration.
