<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **WorldRouter** bundle.

To configure WorldRouter once for all flows, you can also use the [**OpenAI Compatible**](./bundles-openai-compatible) model provider with the base URL `https://inference-api.worldrouter.ai/v1`.

For more information about WorldRouter features and functionality used by WorldRouter components, see the [WorldRouter documentation](https://www.worldrouter.ai/docs/quickstart).

## WorldRouter text generation

This component generates text using WorldRouter's API for Claude, GPT, Gemini, DeepSeek, Kimi, GLM and other chat models.

It can output either a **Model Response** ([`Message`](/data-types#message)) or a **Language Model** ([`LanguageModel`](/data-types#languagemodel)).

Use the **Language Model** output when you want to use a WorldRouter model as the LLM for another LLM-driven component, such as an **Agent** or **Smart Transform** component.

For more information, see [Language model components](/components-models).

### WorldRouter text generation parameters

<PartialParams />

| Name | Type | Description |
|------|------|-------------|
| api_key | SecretString | Input parameter. Your WorldRouter API key for authentication. Create one on the [WorldRouter API Keys dashboard](https://www.worldrouter.ai/dashboard/api-keys). |
| model_name | Dropdown | Input parameter. The model to use for chat completion. Options are fetched live from WorldRouter after you enter an API key; image and video generation models are left out. |
| temperature | Float | Input parameter. Controls randomness in the output. Range: [0.0, 2.0]. Default: 0.7. |
| max_tokens | Integer | Input parameter. The maximum number of tokens to generate. |
