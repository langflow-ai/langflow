FastAF provides public web scraping, Google search, AI extraction, screenshots and structured web data.
Create and verify a [FastAF account](https://fastaf.co/signup/), then obtain an API key from the
[dashboard](https://fastaf.co/dashboard/). Set **FastAF API Key** or use a credential global variable.
The key is sent only in the Bearer authorization header to `https://api.fastaf.co`.
See the [FastAF API documentation](https://fastaf.co/docs/) for current pricing and parameter details.

Each component exposes one uniquely named `fastaf_*` tool in [tool mode](/agents-tools).
Successful executions consume credits: there is no automatic retry, pagination or paid discovery.
A timeout is not proof a request was unbilled. HTTP errors return a safe `error` row, not upstream bodies or credentials.

## Outputs

All components except Screenshot return a [`Table`](/data-types#table) constructed from `Data` records.
Primary result arrays are selected when present; otherwise the response is a flat record.
Nested keys use underscores, nested arrays become JSON strings, and missing list columns become null.
Screenshot returns `Data` with a managed `file_path`, `content_type`, `bytes`, `http_status`,
`credits_used` and `credits_remaining`, not base64 image data. Files use generated names under the
flow's storage namespace (or a generated namespace outside a graph). Local paths belong to the server;
configure durable storage if the image must persist.

## Optional fields and cost controls

Optional boolean controls use **Default**, **true**, or **false**. Default omits the API field.
Optional numbers accept integer text; leave blank to preserve API defaults. This avoids Langflow's
native integer input converting a blank into zero, which would change site-specific wait behavior.
Explicit false and zero are retained. Validation runs before any paid request.

Rendering defaults are site-specific, including Booking. Premium proxies or proxy country targeting
increase the base scrape price. Challenge Mode cannot combine with rendering, premium or proxy country.
Extraction sends a prompt and/or JSON-serialized rules on `/v1/scrape`, not an invented extraction endpoint.
Search/News pages are zero-based, Amazon pages are one-based, and Maps uses offsets in steps of 20.
Each execution retrieves one page only; continuation tokens can be supplied manually.

## FastAF Scrape Page

Retrieve public HTML, markdown, links, images or a summary. Static scrape: 1 credit; options can cost more.

Endpoint: `POST /v1/scrape`. Tool: `fastaf_scrape`.

| Name | Input | Default / behavior |
| --- | --- | --- |
| FastAF API Key (`fastaf_api_key`) | SecretString | Required secret; no default.Create an API key at https://fastaf.co/dashboard/. Calls consume FastAF credits; avoid blind retries. |
| Page URL (`url`) | str | Required. Public HTTP(S) URL. Private targets and login paths are refused by FastAF. |
| Render JavaScript (`dynamic`) | str | Default: `Default`. Default preserves site rules, including Booking rendering. |
| Premium Proxies (`premium`) | str | Default: `Default`. 10 base credits; 25 with rendering. |
| Proxy Country (`proxy_country`) | str | Optional; blank omitted. ISO country code; enables premium-tier pricing. |
| Browser Wait (ms) (`wait`) | str | Optional; blank omitted. 0-35000; does not enable rendering. Blank preserves site defaults. Integer; leave blank for the API default. |
| Challenge Mode (`challenge_mode`) | str | Default: `Default`. 10 base credits; incompatible with rendering/premium/country. |
| Output Format (`format`) | str | Default: `html`. One format; an AI summary adds 10 credits. |
| Proxy Session (`session_number`) | str | Optional; blank omitted. Repeat an ID to request the same proxy; expires after 60s idle. |

## Security and limits

Only the fixed FastAF HTTPS origin receives the key. Certificate verification is enabled;
redirects and environment proxy inheritance are disabled. Responses are capped at 64 MiB,
with 120-second I/O timeouts and a checked read deadline. Error outputs never include request
headers or upstream response bodies. Unknown credit counts remain null.
