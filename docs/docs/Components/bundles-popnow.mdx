<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **PopNow** bundle.

To configure PopNow once for all flows, you can also use the [**OpenAI Compatible**](./bundles-openai-compatible) model provider with the base URL `https://api.popnow.ai/v1`.

For more information about PopNow features and functionality used by PopNow components, see the [PopNow documentation](https://popnow.ai/docs/chat).

## PopNow text generation

This component generates text using PopNow's API for Claude, GPT, Gemini, DeepSeek, Kimi and other chat models.

It can output either a **Model Response** ([`Message`](/data-types#message)) or a **Language Model** ([`LanguageModel`](/data-types#languagemodel)).

Use the **Language Model** output when you want to use an PopNow model as the LLM for another LLM-driven component, such as an **Agent** or **Smart Transform** component.

For more information, see [Language model components](/components-models).

### PopNow text generation parameters

<PartialParams />

| Name | Type | Description |
|------|------|-------------|
| api_key | SecretString | Input parameter. Your PopNow API key for authentication. Create one in the [PopNow API console](https://popnow.ai/api/console/keys). |
| model_name | Dropdown | Input parameter. The model to use for chat completion. Options are fetched live from PopNow after you enter an API key. |
| temperature | Float | Input parameter. Controls randomness in the output. Range: [0.0, 2.0]. Default: 0.7. |
| max_tokens | Integer | Input parameter. The maximum number of tokens to generate. |
