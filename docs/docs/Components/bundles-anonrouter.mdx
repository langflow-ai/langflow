<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **AnonRouter** bundle.

To configure AnonRouter once for all flows, you can also use the [**OpenAI Compatible**](./bundles-openai-compatible) model provider with the base URL `https://api.anonrouter.ai/v1`.

For more information about AnonRouter features and functionality used by AnonRouter components, see the [AnonRouter documentation](https://docs.anonrouter.ai).

## AnonRouter text generation

This component generates text using AnonRouter's OpenAI-compatible API, which routes requests to models from many providers.

It can output either a **Model Response** ([`Message`](/data-types#message)) or a **Language Model** ([`LanguageModel`](/data-types#languagemodel)).

Use the **Language Model** output when you want to use an AnonRouter model as the LLM for another LLM-driven component, such as an **Agent** or **Smart Transform** component.

For more information, see [Language model components](/components-models).

### Authentication

The component uses an AnonRouter inference key, which has the prefix `ar_`.

The key must have OpenAI-compatible access enabled, which AnonRouter calls [compatibility mode](https://docs.anonrouter.ai/compatibility). The AnonRouter dashboard enables this by default for new keys. A key created with the setting turned off is restricted to AnonRouter's single-use ticket flow, which this component does not implement, and returns a `permission_error`.

The **Model** list is fetched from `https://api.anonrouter.ai/v1/models` with your key. This endpoint requires authentication, so the list stays empty until you enter a key.

### AnonRouter text generation parameters

<PartialParams />

| Name | Type | Description |
|------|------|-------------|
| api_key | SecretString | Input parameter. Your AnonRouter inference key for authentication. |
| model_name | Dropdown | Input parameter. The model to use for chat completion. Options are fetched live from the AnonRouter model catalog with your key. Model IDs keep their `creator/model` form, such as `meta-llama/llama-3.3-70b`. |
| temperature | Float | Input parameter. Controls randomness in the output. Range: [0.0, 2.0]. Default: 0.7. |
| max_tokens | Integer | Input parameter. The maximum number of tokens to generate. |
