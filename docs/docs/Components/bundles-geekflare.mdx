<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **Geekflare** bundle.

All components call the [Geekflare API](https://geekflare.com) and need a Geekflare API key. Get one from [dash.geekflare.com](https://dash.geekflare.com). For details on the underlying API, see the [Geekflare API documentation](https://docs.geekflare.com).
If a request fails, for example because the API key is missing or invalid, the output contains an `error` field that describes the problem.

## Geekflare Search

This component runs a web, news, or image search through Geekflare.
Turn on **Google SERP** to get the organic results of the full Google results page for a country or city.

It outputs the results as a [`Table`](/data-types#table) with `title`, `link`, `snippet`, and `position` columns. The `text` of each row is the result snippet.

In [tool mode](/agents-tools), the component exposes a single tool named `geekflare_search` that an [**Agent** component](/agents) can call with a search query.

### Geekflare Search parameters

| Name | Type | Description |
|------|------|-------------|
| Search Query (`input_value`) | String | Input parameter. The search query to execute. |
| Geekflare API Key (`geekflare_api_key`) | SecretString | Input parameter. Your Geekflare API key. |
| Source (`source`) | String | Input parameter. `web`, `news`, or `images`. Default: `web`. |
| Google SERP (`serp`) | Boolean | Input parameter. Return the organic results of the full Google results page. Default: `false`. |
| Country (`location`) | String | Input parameter. Country code for the results, for example `us` or `de`. Optional. |
| City (`city`) | String | Input parameter. City for localized results, for example `London,England,United Kingdom`. Takes priority over Country. Optional. |
| Max Results (`max_results`) | Integer | Input parameter. The maximum number of results to return, from `1` to `100`. Default: `10`. |

## Geekflare Scrape

This component fetches a public web page and returns its content as a [`Data`](/data-types#data) object whose `text` is the page content.

In tool mode, it exposes a tool named `geekflare_scrape`.

### Geekflare Scrape parameters

| Name | Type | Description |
|------|------|-------------|
| URL (`url`) | String | Input parameter. Full URL of the page, or a domain such as `example.com`. |
| Geekflare API Key (`geekflare_api_key`) | SecretString | Input parameter. Your Geekflare API key. |
| Format (`output_format`) | String | Input parameter. `markdown`, `markdown-llm`, `text`, `text-llm`, `html`, or `html-llm`. The `-llm` variants strip boilerplate. Default: `markdown`. |
| Template (`template`) | String | Input parameter. `product` or `contact` for structured data, or `none`. Default: `none`. |

## Geekflare Website Check

This component runs one website check and returns the API result as a [`Data`](/data-types#data) object.
The available checks are `site_status`, `dns_records`, `dnssec`, `tls_scan`, `redirect_check`, `broken_links`, `load_time`, `mixed_content`, and `lighthouse`. The `lighthouse` check can take a minute or more.

In tool mode, it exposes a tool named `geekflare_website_check`.

### Geekflare Website Check parameters

| Name | Type | Description |
|------|------|-------------|
| URL (`url`) | String | Input parameter. Website URL or domain, for example `example.com`. |
| Geekflare API Key (`geekflare_api_key`) | SecretString | Input parameter. Your Geekflare API key. |
| Check (`check`) | String | Input parameter. Which check to run. Default: `site_status`. |
