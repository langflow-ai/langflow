The FlashData bundle supplies Google and YouTube research data for Langflow flows and Agents.
It includes 15 source capabilities, with separate submit, status, and result components for asynchronous YouTube delivery.

## Install and configure

This bundle is proposed for inclusion and has not yet been merged or released to PyPI.
In a Langflow 1.13 development checkout containing this contribution, install from source:

```bash
uv pip install -e src/bundles/flashdata
lfx extension validate src/bundles/flashdata/src/lfx_flashdata
```

Restart Langflow, then open **Bundles → FlashData**.
Get an API key from [FlashData](https://flashdata.dev) and save it as a **Credential** global variable.
API requests use paid FlashData Credits. Installation is free; API usage is not.

Each component has a fixed source, an agent-compatible primary input, optional source parameters, and a JSON output.
Use **Parser** with template `{text}` to turn the response into a Message for **Chat Output**.
In **Tool Mode**, connect the Tool output to an Agent; its model is configured and billed separately.

## Errors and billing

Invalid parameters are rejected before the request. API errors identify authentication, Credits, permission, and rate-limit failures without returning raw response bodies.
No request is retried automatically. A timeout after submission can mean a job was accepted and charged; inspect Jobs before submitting again.
Download Submit requires a separate customer-storage credential and explicit permission to submit. Status and Result only inspect the saved job.
