<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **TrustedRouter** bundle.

To configure TrustedRouter once for all flows, you can also use the [**OpenAI Compatible**](./bundles-openai-compatible) model provider with the base URL `https://api.trustedrouter.com/v1`.

For more information about TrustedRouter features and functionality used by TrustedRouter components, see the [TrustedRouter documentation](https://trustedrouter.com/docs).

## TrustedRouter text generation

This component generates text using TrustedRouter's OpenAI-compatible API, which routes requests to models from Anthropic, OpenAI, Google and other providers.

It can output either a **Model Response** ([`Message`](/data-types#message)) or a **Language Model** ([`LanguageModel`](/data-types#languagemodel)).

Use the **Language Model** output when you want to use a TrustedRouter model as the LLM for another LLM-driven component, such as an **Agent** or **Smart Transform** component.

For more information, see [Language model components](/components-models).

### TrustedRouter text generation parameters

<PartialParams />

| Name | Type | Description |
|------|------|-------------|
| api_key | SecretString | Input parameter. Your TrustedRouter API key for authentication. Create one in the [TrustedRouter console](https://trustedrouter.com/console/api-keys). |
| model_name | Dropdown | Input parameter. The model to use for chat completion, such as `anthropic/claude-sonnet-4.5`. Default: `trustedrouter/auto`. Options are fetched live from the public TrustedRouter model list when you refresh the field. |
| temperature | Float | Input parameter. Controls randomness in the output. Range: [0.0, 2.0]. Default: 0.7. |
| max_tokens | Integer | Input parameter. The maximum number of tokens to generate. |
