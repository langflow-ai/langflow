<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support third-party integrations with Langflow.

The **MrScraper** bundle provides seven components that follow the [MrScraper Scraper API reference](https://docs.mrscraper.com/docs/api/scraper-api/scrape-html): **Status**, **Scrape HTML**, **Scrape Markdown**, **Get Screenshot**, **Scrape Brand**, **Scrape JSON**, and **Web Search**. They use `mrscraper-sdk` version `0.12.x`. Install the provider dependencies with `pip install "lfx-bundles[mrscraper]"`, then enter your API token from [the MrScraper app](https://app.mrscraper.com) in each component's **MrScraper API Token** field.

All seven components return the API payload as [`Data`](/data-types#json). The SDK's `status_code` and `headers` envelope is removed. Object responses are preserved; text responses are wrapped in a field (`html` for **Scrape HTML** and `markdown` for **Scrape Markdown**) so they remain valid Langflow data. API, authentication, and network errors fail the component. The API token is sent in request headers, never in the URL.

## Shared page settings

**Scrape HTML**, **Scrape Markdown**, **Get Screenshot**, and **Scrape JSON** share these settings in their advanced options. **Scrape Brand** accepts **Timeout**, **Warm Start**, and **Geo Code**. Blank optional fields are left out of the request. These four components always send `saveResult=true`, so results are saved to the dashboard Result tab, and they never send a token cap.

| Parameter | Default | Description |
|-----------|---------|-------------|
| Browser Rendering (`browser_rendering`) | `Auto` | Whether to load the page in a browser: `Enabled` always does and `Disabled` never does. `Auto` loads the page without a browser first and switches to a browser automatically if the request is blocked. Not shown on **Get Screenshot**, which always renders. |
| Timeout (seconds) (`timeout`) | `300` | Maximum seconds to wait for the scrape, from 1 to 330. The HTTP request allows 30 additional seconds. On **Scrape Brand**, it is blank by default and sent only when set. |
| Warm Start (`warm_start`) | `false` | Whether to open the site's home page first to warm the session before loading the target URL. Not shown on **Get Screenshot**. |
| Block Resources (`block_resources`) | `false` | Whether to block images, fonts, and stylesheets while loading the page. Not shown on **Get Screenshot**. |
| Wait for Selector (`wait_for_selector`) | Blank | CSS selector or text to wait for on the page before returning the result, up to 500 characters. A selector needs a rendered page, so don't combine it with **Browser Rendering** `Disabled`. |
| Action (`action`) | Blank | Scraper action that routes the request or simply flags it, useful for separating analytics per domain. **Scrape HTML** and **Scrape Markdown** only. |
| Geo Code (`geo_code`) | Blank | Two-letter country code to load the page from, sent in lowercase. Blank uses the API default (United States). |
| Max Age (milliseconds) (`max_age`) | `0` | Return a cached result of the same request when it is newer than the selected age. A cached result costs the same tokens as the original scrape. Up to `604800000` (7 days); `0` always scrapes fresh. |
| Max Retries (`max_retries`) | Blank | Maximum number of retries, as a nonnegative integer; `0` is preserved. Blank means no limit. |

## MrScraper Status

Return the raw account status API response without summarizing, redacting body fields, or adding calculated fields. This component calls `GET https://api.app.mrscraper.com/api/v1/subscription-accounts` and takes only the **MrScraper API Token**.

The output is the account record as the API sends it, with account details nested under `data`, such as `data.tokenLimit`, `data.tokenUsage`, `data.subscriptionItem`, and `data.scraperAllowance`. The record includes account identity and billing fields, so pass only the fields you need to a language model. For example, connect **Status** to a **Parser** to read `data.tokenUsage` before starting a scraping workflow.

## MrScraper Scrape HTML

Retrieve the raw HTML of a page. Browser rendering is optional. This component sends `GET https://api.mrscraper.com` with `html=true` and `markdown=false`, the **URL**, and the shared page settings, including **Action**.

| Parameter | Default | Description |
|-----------|---------|-------------|
| URL (`url`) | Required | Absolute HTTP or HTTPS URL of the page to process. Available in Tool Mode. |
| Screenshot (`screenshot`) | `None` | Screenshot to capture with the HTML: `None` for no screenshot, `full` for the entire page, `top` for the first viewport, or a `WIDTHxHEIGHT` viewport from 100 to 3840 pixels with an optional `-ZOOM` percent from 25 to 300, such as `1280x800` or `1920x1080-75`. Setting a screenshot also sends `browserRendering=true`, even when **Browser Rendering** is `Disabled`. |

Without a screenshot, the output is `{"html": "..."}`. With a screenshot, the API returns JSON with `html` and a base64 `screenshot`, which passes through unchanged.

## MrScraper Scrape Markdown

Retrieve a page as clean Markdown. Browser rendering is optional. This component sends `GET https://api.mrscraper.com` with `markdown=true`, `html=false`, and `screenshot=false`, the **URL**, and the shared page settings, including **Action**. The output is `{"markdown": "..."}`.

## MrScraper Get Screenshot

Capture a base64 PNG screenshot of the full page. Browser rendering is always enabled. This component sends `GET https://api.mrscraper.com` with `screenshot=full`, `html=false`, `markdown=false`, and `browserRendering=true`, the **URL**, and the shared **Timeout**, **Wait for Selector**, **Geo Code**, **Max Age**, and **Max Retries** settings. The output contains the base64 `screenshot` and the page `html`, which the API includes even though `html=false` is sent.

## MrScraper Scrape Brand

Extract a website's colors, typography, logos, and social links as JSON. This component sends `GET https://api.mrscraper.com` with `action=brand-scraping`, `bundle=none`, the **URL**, and **Warm Start** (default `false`). **Timeout** (1 to 330 seconds) and **Geo Code** are blank by default and sent only when set. The HTTP request allows the timeout plus 30 seconds, or 330 seconds when **Timeout** is blank.

The output contains `message` and a `data` object with `job_id`, `status`, `url`, `final_url`, `brand`, and `error`. Brand fields can be `null` when a site does not declare them.

## MrScraper Scrape JSON

Extract structured JSON from a page using a natural-language prompt. Append `Json Schema:` and a JSON schema to shape the output. This component sends `GET https://api.mrscraper.com` with `agent=general`; when the encoded URL would exceed 8,000 characters, it switches to `POST` with `url`, `prompt`, and `agent` in a JSON body and the other settings in the query.

| Parameter | Default | Description |
|-----------|---------|-------------|
| URL (`url`) | Required | Absolute HTTP or HTTPS URL of the page to process. Available in Tool Mode. |
| Prompt (`prompt`) | `Extract all data as complete as possible.` | Instructions describing the data to extract. Append `Json Schema:` and a JSON schema to shape the output. Available in Tool Mode. |
| Include HTML (`html`) | `true` | Whether to include the page HTML in the response. Disable it for a smaller response. |
| Include Screenshot (`screenshot`) | `false` | Whether to include a base64 screenshot in the response. |

**Scrape JSON** also accepts the shared page settings except **Action**, and always sends `saveResult=true`. Extracted fields are in `data`; the output also contains `success`, `token_usage`, `status`, and `error`. A failed run returns `success: false` and is not billed.

## MrScraper Web Search

Search the web and return ranked results with titles, URLs, descriptions, and sources. This component sends `GET https://api.mrscraper.com` with `action=websearch`.

| Parameter | Default | Description |
|-----------|---------|-------------|
| Search Query (`query`) | Required | Search query text, trimmed before sending, containing 1 to 1000 characters. Available in Tool Mode. |
| Country (`country`) | Blank | Two-letter country code to search from, sent in lowercase. Blank uses the API default (United States). |
| Number of Results (`num_results`) | `10` | Number of search results to request, as an integer from 10 to 100. Fewer results may be returned. |

The output contains `success`, `message`, and a `data` array whose rows include `rank`, `title`, `url`, `description`, and `source`. The HTTP request waits up to 120 seconds.

## Updating existing flows

**MrScraper Account** is now displayed as **MrScraper Status**, and **MrScraper Scraper API** as **MrScraper Scrape HTML**. Their classes and saved-flow identifiers remain `MrscraperAccount` and `MrscraperFetchHtml`, **Web Search** keeps `MrscraperWebSearch`, and every output name remains `data`. Review these changes in existing flows:

- **Status** returns the raw account record instead of a calculated summary and no longer has a timeout. Read usage from `data.tokenUsage` and `data.tokenLimit`.
- **Scrape HTML** always requests HTML. Use **Scrape Markdown** for Markdown and **Get Screenshot** for a full-page screenshot, or set **Screenshot** on **Scrape HTML**. **Visit Home Page First** is now **Warm Start**. The **Super**, **Proxy Country**, **Use Proxy**, **Custom Proxy**, **Bypass Proxy**, **Cookie Jar**, **Target Headers**, **Stream**, and **Discard Token Secret** settings were removed because the API reference no longer lists them. **Geo Code** and **Max Retries** are now blank by default. The **Save Result** and **Token Cap** settings were removed: results are always saved to the dashboard Result tab, and no token cap is sent.
- **Web Search** takes a **Search Query** with optional **Country** and **Number of Results**. Re-enter the query in existing nodes; Google URL parsing and the **Raw HTML**, **Format**, **Region**, **Language**, **Page**, **Render JavaScript**, and **Timeout** settings were removed.

The AI Agent Scraper, Batch Scrape URLs, Crawl Website, Get Result Detail, Get Results, Run AI Scraper, and Run Manual Scraper components were retired in Langflow 1.13.0 and have no equivalent. Saved nodes of these components still load as retired placeholders with their fields and connections, but running one fails with a message that names **MrScraper Scrape HTML** as the replacement. Use **Scrape JSON** for prompt-driven extraction from a single page.

Flows saved with one of these components still load. `lfx upgrade` reports each such node as retired, and running the flow fails with a message that names **Scraper API** as the replacement.

For more information, see the [MrScraper documentation](https://docs.mrscraper.com).
