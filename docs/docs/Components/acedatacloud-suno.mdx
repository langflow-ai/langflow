**Suno by Ace Data Cloud** lets you generate instrumental music in Langflow. This is an Ace Data Cloud integration, not a claim of endorsement by the Suno service owner. Search **suno** or **suno** in the component palette; choose **Suno Generate by Ace Data Cloud** and **Suno Retrieve Task by Ace Data Cloud**.

## 1. Install and find the nodes

For a currently available installation, ask the Langflow administrator to follow the [public installation instructions](https://github.com/AceDataCloud/LangflowAceDataCloud#1-install-the-extension) and install the [public v0.1.2 GitHub wheel](https://github.com/AceDataCloud/LangflowAceDataCloud/releases/tag/v0.1.2) in the same Python environment, then restart. The branded 0.1.3 node labels described below are still a candidate, so v0.1.2 installation does not prove those labels have shipped. Default inclusion is proposed in [the open Langflow PR](https://github.com/langflow-ai/langflow/pull/15659). The [proposed official bundle page](./bundles-acedatacloud.mdx) becomes an installation entry only after acceptance and publication; the public URL may return404 before then. A local installation does not prove official publication.

After installation and restart, search **suno** under Components, or open **Components → Ace Data Cloud**. Import the [no-key Suno flow](https://github.com/AceDataCloud/LangflowAceDataCloud/blob/main/examples/suno.json) if you prefer ready connections.

A **service-only 0.1.3 source candidate** is also available for review in [Ace package PR #6](https://github.com/AceDataCloud/LangflowAceDataCloud/pull/6). Check out that exact head, then run `python -m pip install ./packages/suno` from its repository root in Langflow's Python environment. Restart and open the service's **by Ace Data Cloud** category. The package registers just Generate and Retrieve Task, without installing the aggregate or adding another chat provider. It is not yet a published package listing. Use its bundled `examples/` JSONs; these have service-specific IDs, while the aggregate examples below retain their existing IDs. All five service packages can coexist. If the aggregate is installed too, both categories remain visible for saved-flow compatibility.

## 2. Get an application API Token

Register or sign in at [Ace Data Cloud → Applications](https://platform.acedata.cloud/console/applications?utm_source=langflow&utm_medium=referral&utm_campaign=evergreen&utm_content=langflow_suno_guide_api_key). If there is no **General application**, choose **Initialize General Application**. Copy its existing API Key or choose **Manage Keys → Create** for a dedicated Langflow token. Check Suno access, expiry, usage limit, [current price](https://platform.acedata.cloud/models?utm_source=langflow&utm_medium=referral&utm_campaign=evergreen&utm_content=langflow_suno_guide_pricing) and balance. If **Allowed APIs** is restricted, allow both `/suno/audios` and `/suno/tasks`.

Copy only the raw token, without `Bearer ` or quotes. Do not use an account-management token. The Console images below are real existing screenshots from the Ace guide (2026-10-12 source revision); displayed keys are redacted.

## 3. Save the token in Langflow

Open **Settings → Global Variables → Add New**. Choose **Credential**, name it `ACEDATACLOUD_API_KEY`, paste the raw token into **Value**, and save. On both Suno nodes, use the globe icon in **Ace Data Cloud API key** to select that credential. Never put a literal token in prompts or exported flow JSON.

![Real Langflow Create Credential dialog, before a key is entered](https://raw.githubusercontent.com/AceDataCloud/LangflowAceDataCloud/59beda518889ff106f64da9caaad56e59690a6e4/_assets/tutorial/17-create-credential.png)

## 4. Configure one submission and the same-task reader

Connect **Suno Generate by Ace Data Cloud → Suno Retrieve Task by Ace Data Cloud → Chat Output**. The reader's **Submitted task** input receives Generate's result. Bind the Credential on both nodes, then use these existing first-run values:

| Field | First-run value |
| --- | --- |
| Prompt (`prompt`) | `A short gentle instrumental piano melody for a sunrise, no vocals.` |
| Model (`model`) | `chirp-v6` |
| Instrumental (`instrumental`) | `True` |
| Target duration (seconds) (`duration`) | `10` |
| Additional route parameters | `{"async": true}` |
| Retrieve Task → Wait up to seconds | `240` |

The [flow file](https://github.com/AceDataCloud/LangflowAceDataCloud/blob/main/examples/suno.json) contains the exact prompt and route-specific values. Model availability and price can change. Review them before clicking Run; do not replace a model silently.

## 5. Read the result without paying for a second submission

Click the Chat Output run control **once**. Generate makes one paid submission. The connected reader queries the same task; a green Langflow node or preview does not prove media completion. The terminal success output has `status=succeeded`, `success=true`, and `media_urls` with result links.

If the wait ends with `pending`, use the separate [retrieve-only Suno flow](https://github.com/AceDataCloud/LangflowAceDataCloud/blob/main/examples/retrieve_only/suno.json), paste the original task ID, and bind the same Credential. Do not rerun Generate just to check status. If a submission was accepted but its response timed out, recover the original ID from request history before considering another submission.

Check [Usage History](https://platform.acedata.cloud/console/usages?utm_source=langflow&utm_medium=referral&utm_campaign=evergreen&utm_content=langflow_suno_guide_usage) against that original task or trace. Charges are Credits, not a fixed USD amount. Historical component tests are documented in the [capability matrix](https://github.com/AceDataCloud/LangflowAceDataCloud/blob/main/CAPABILITIES.md); a component test is not proof that every UI path or advanced API action has been exercised.

## Troubleshooting

- **No search result:** confirm the bundle is installed in the server's Python environment, restart it, then search the service name. The pending branded labels require the corresponding release.
- **401/403:** check the raw application token, service access and allowed submit/query routes.
- **400:** check model and route-specific fields against the current guide.
- **429:** wait and reduce concurrency; keep automatic paid retries off.
- **Pending/timeout:** query the original task; do not submit another generation to poll.

The extension is free; Ace API use follows current prices and your balance. See [Ace Data Cloud bundle scope and privacy](./bundles-acedatacloud.mdx).
