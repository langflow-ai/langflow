<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **HopBase** bundle.

To configure HopBase once for all flows, you can also use the [**OpenAI Compatible**](./bundles-openai-compatible) model provider with the base URL `https://api.hop-base.com/v1`.

For more information about HopBase features and functionality used by HopBase components, see the [HopBase documentation](https://hop-base.com/en/docs).

## HopBase text generation

This component generates text using [HopBase](https://hop-base.com), an API gateway with one OpenAI-compatible base URL for Claude, GPT, Gemini, DeepSeek, Qwen, GLM and other models.

It can output either a **Model Response** ([`Message`](/data-types#message)) or a **Language Model** ([`LanguageModel`](/data-types#languagemodel)).

Use the **Language Model** output when you want to use a HopBase model as the LLM for another LLM-driven component, such as an **Agent** or **Smart Transform** component.

For more information, see [Language model components](/components-models).

### HopBase text generation parameters

<PartialParams />

| Name | Type | Description |
|------|------|-------------|
| api_key | SecretString | Input parameter. Your HopBase API key for authentication. Create one on the [HopBase API keys page](https://api.hop-base.com/keys). |
| model_name | Dropdown | Input parameter. The model to use for chat completion. Options are fetched live from HopBase after you enter an API key, and list the models enabled for that key. Select a chat model, such as `claude-sonnet-5-5` or `gpt-6.1-sol`. |
| temperature | Float | Input parameter. Controls randomness in the output. Range: [0.0, 2.0]. Default: 0.7. |
| max_tokens | Integer | Input parameter. The maximum number of tokens to generate. |
