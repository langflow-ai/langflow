## CrawlerData Search

This component runs a Google search through the [CrawlerData API](https://crawlerdata.com) and returns the organic results. When Google shows an AI Overview for the search, the component also returns it, with the pages it cites.

Get an API key from [app.crawlerdata.com](https://app.crawlerdata.com). For details on the underlying API, see the [CrawlerData Google Search API documentation](https://crawlerdata.com/apis/google-search-api).

It outputs the results as a [`Table`](/data-types#table) with `title`, `link`, `snippet`, and `position` columns. The `text` of each row is the result snippet.
If **Include AI Overview** is enabled and Google shows an AI Overview, it is added as the first row with `title` set to `Google AI Overview` and `position` set to `0`. Its `snippet` holds the overview text followed by the pages it cites.
If the request fails, for example because the API key is missing or invalid or the account is out of credits, the table contains a single row with an `error` column that describes the problem.

Each search uses one CrawlerData credit, and failed requests are not charged.

In [tool mode](/agents-tools), the component exposes a single tool named `crawlerdata_search` that an [**Agent** component](/agents) can call with a search query.

### CrawlerData Search parameters

| Name | Type | Description |
|------|------|-------------|
| Search Query (`input_value`) | String | Input parameter. The search query to run on Google. |
| CrawlerData API Key (`crawlerdata_api_key`) | SecretString | Input parameter. Your CrawlerData API key. |
| Country (`country`) | String | Input parameter. Two-letter country code for the results, for example `us`, `gb`, or `de`. Default: `us`. Optional. |
| Language (`language`) | String | Input parameter. Two-letter language code, for example `en` or `de`. Optional. |
| Device (`device`) | Dropdown | Input parameter. `desktop` or `mobile` results. Default: `desktop`. |
| Location (`location`) | String | Input parameter. City-level targeting, for example `Austin,Texas,United States`. Optional. |
| Max Results (`max_results`) | Integer | Input parameter. The maximum number of organic results to return, from `1` to `100`. Google returns about 10 per page. Default: `10`. |
| Page (`page`) | Integer | Input parameter. The result page to fetch, starting at `1`. Default: `1`. |
| Include AI Overview (`include_ai_overview`) | Boolean | Input parameter. Add Google's AI Overview and its cited pages as the first row when Google shows one. Default: enabled. |
