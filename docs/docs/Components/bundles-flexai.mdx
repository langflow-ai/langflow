<Icon name="Blocks" aria-hidden="true" /> [**Bundles**](/components-bundle-components) contain custom components that support specific third-party integrations with Langflow.

This page describes the components that are available in the **FlexAI** bundle.

To configure FlexAI once for all flows, you can also use the [**OpenAI Compatible**](./bundles-openai-compatible) model provider with the base URL `https://api.flex.ai/v1`.

For more information about FlexAI features and functionality used by FlexAI components, see the [FlexAI inference API documentation](https://docs.flex.ai/inference-api/quickstart).

## FlexAI text generation

This component generates text using open models served by FlexAI's OpenAI-compatible inference API.

It can output either a **Model Response** ([`Message`](/data-types#message)) or a **Language Model** ([`LanguageModel`](/data-types#languagemodel)).

Use the **Language Model** output when you want to use a FlexAI model as the LLM for another LLM-driven component, such as an **Agent** or **Smart Transform** component.

For more information, see [Language model components](/components-models).

### FlexAI text generation parameters

<PartialParams />

| Name | Type | Description |
|------|------|-------------|
| api_key | SecretString | Input parameter. Your FlexAI API key for authentication. Create a key at [platform.flex.ai](https://platform.flex.ai). |
| model_name | Dropdown | Input parameter. The model to use for chat completion. After you enter an API key, options are fetched live from the FlexAI model catalog. Default: `DeepSeek-V4-Flash-0731`. |
| temperature | Float | Input parameter. Controls randomness in the output. Range: [0.0, 2.0]. Default: 0.7. |
| max_tokens | Integer | Input parameter. The maximum number of tokens to generate. |
